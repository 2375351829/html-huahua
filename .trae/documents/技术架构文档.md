## 2. 技术描述
- 前端：React@18 + TypeScript + Tailwind CSS + Vite
- 初始化工具：Vite
- 后端：无（纯前端实现）
- 数据库：无
- 第三方库：
  - reactflow：用于ER图画布交互
  - monaco-editor：用于SQL代码编辑和语法高亮
  - file-saver：用于导出文件
  - lucide-react：用于图标
  - mermaid：用于生成流程图、时序图、用例图等多种图表类型

## 6. 数据模型
### 6.1 数据模型定义
```mermaid
erDiagram
    TABLE ||--o{ FIELD : has
    TABLE ||--o{ RELATIONSHIP : has
    RELATIONSHIP ||--o{ TABLE : references
```

### 6.2 数据定义
- Table：表结构
  - id: string
  - name: string
  - comment: string
  - fields: Field[]
  - relationships: Relationship[]

- Field：字段结构
  - id: string
  - name: string
  - type: string
  - isPrimaryKey: boolean
  - isNullable: boolean
  - defaultValue: string | null
  - comment: string

- Relationship：关系结构
  - id: string
  - sourceTable: string
  - sourceField: string
  - targetTable: string
  - targetField: string
  - type: 'one-to-one' | 'one-to-many' | 'many-to-many'

### 6.3 状态管理
- 使用Zustand进行状态管理，存储：
  - SQL输入文本
  - 解析后的表结构
  - ER图布局信息
  - 样式配置
  - 导出设置
  - 图表生成配置（包括图表类型、参数等）

### 6.4 图表生成模块
- 使用Mermaid库生成多种图表类型：
  1. 三线表：将SQL表结构转换为Markdown三线表格式
  2. 用例图：根据表关系和业务逻辑生成Mermaid用例图
  3. 功能模块图：根据系统功能生成Mermaid流程图
  4. 流程图：根据SQL操作生成Mermaid流程图
  5. 时序图：根据系统交互生成Mermaid时序图
  6. 数据流图：根据数据流动过程生成Mermaid流程图

- 图表导出功能：
  - 支持导出为PNG、SVG等格式
  - 支持复制图表代码
  - 支持直接嵌入到文档中
