# 赛博狂欢 - Cyber Rave

一个充满未来感的音频可视化互动网页，融合了3D粒子效果、音频合成和实时视觉反馈。

## 项目简介

赛博狂欢是一个单文件HTML应用，通过Three.js实现3D粒子效果，Web Audio API实现音频合成与分析，Canvas 2D实现频谱可视化和数字雨效果，打造出一个沉浸式的赛博朋克风格音频可视化体验。

## 核心特性

### 视觉效果
- **3D粒子系统**：双环结构，5000个粒子（桌面）/2500个粒子（移动）
- **后处理效果**：UnrealBloomPass泛光效果和AfterimagePass残影效果
- **频谱可视化**：三种样式（环形放射、垂直条形、圆形波纹）
- **数字雨**：Canvas 2D绘制的动态数字雨效果
- **全息卡片**：3D倾斜效果的信息卡片
- **扫描线**：模拟CRT显示器的扫描线效果
- **闪白效果**：节拍触发的全屏闪白

### 音频系统
- **内置合成器**：Kick（60Hz正弦波）、Hi-hat（白噪声高通）、Bassline（锯齿波）
- **16步进序列器**：可调节BPM（60-180）
- **麦克风混合**：支持外接麦克风输入
- **频率分析**：实时音频频谱数据驱动视觉效果

### 控制中心
- **自动隐藏/唤出**：右侧滑出式面板，可隐藏为悬浮球
- **全面控制**：音频、视觉、性能参数调节
- **频谱样式**：三种可视化样式切换
- **主题切换**：四种色彩主题（紫粉狂欢、青蓝冷色、熔金红、冰白单色）
- **视觉模式**：四种视觉模式（赛博狂欢、脉冲矩阵、全息蓝调、故障增强）
- **性能调节**：粒子数量、泛光强度、残影阻尼调节
- **快捷键**：全面的键盘快捷键支持

### 响应式设计
- 桌面端：完整功能，5000粒子
- 移动端：优化性能，2500粒子，简化后处理

## 快速开始

1. 直接在浏览器中打开 `cyber-rave.html` 文件
2. 点击中央的 "▶ START RAVE" 按钮启动音频
3. 使用右侧控制面板调整各种参数
4. 按 `H` 键隐藏/显示控制面板
5. 按空格键播放/暂停音频

## 技术栈

- **前端框架**：原生HTML5、CSS3、JavaScript
- **3D渲染**：Three.js 0.160
- **动画库**：GSAP 3.12
- **音频处理**：Web Audio API
- **可视化**：Canvas 2D API
- **后处理**：Three.js PostProcessing（UnrealBloomPass, AfterimagePass）

## 核心功能说明

### 控制面板
- **音频控制**：播放/暂停、音量调节、BPM调节、节奏预设、麦克风开关
- **视觉模式**：四种视觉效果模式切换
- **色彩主题**：四种色彩方案切换
- **性能与特效**：粒子数量、泛光强度、残影阻尼调节
- **频谱样式**：三种频谱可视化样式切换
- **功能开关**：数字雨、自动滚屏、冻结动画
- **系统功能**：重置默认、全屏切换

### 键盘快捷键
- `[M]` - 麦克风开关
- `[Space]` - 播放/暂停
- `[H]` - 控制面板显示/隐藏
- `[V]` - 视觉模式切换
- `[D]` - 数字雨开关
- `[F]` - 冻结动画
- `[F11]` - 全屏切换

## 性能优化

1. **移动端适配**：自动降低粒子数量，关闭AfterimagePass
2. **动态粒子系统**：根据设置实时调整粒子数量
3. **后处理调节**：可根据设备性能调整泛光强度
4. **资源管理**：及时释放未使用的音频资源

## 浏览器兼容性

## 注意事项

1. **音频权限**：首次访问需要用户授权麦克风使用
2. **WebGL支持**：需要浏览器支持WebGL 2.0
3. **性能要求**：复杂视觉效果可能在低配置设备上卡顿
4. **全屏模式**：需要用户交互才能进入全屏
